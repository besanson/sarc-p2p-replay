# paper/

Markdown draft generated from `results/` slots by `scripts/fill_paper.py` (Phase D).

| file | holds |
|---|---|
| `template.md` | the paper with a placeholder for every number |
| `paper.md` | the generated draft |
| `filled-template.json` | every placeholder of `template.md`: its text in `paper.md`, source file, key, raw value and span (the typed-numeral lint reads the spans) |
| `figures/` | the figures, SVG and PDF, from `scripts/figures.py` |

These are derived records of the paper: they regenerate with it (D-D-3). Slot files under
`results/` never change once committed.
